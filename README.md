# Make the coolest art

Entry for the make.fun bounty "Make the coolest art"
(https://make.fun/bounty/coolest-art-01).

`main.py` copies the bundled artwork (`koi.png` — a colossal koi fish
made of glowing neon light swimming through the night sky above a
futuristic Tokyo street, with a glowing "make.fun" neon sign on one
of the buildings) to `/output/entry.png`. Deterministic: the same
bytes on every run. No network, no randomness.

Run: `python3 main.py` (Python 3.13). Output: `/output/entry.png`.
